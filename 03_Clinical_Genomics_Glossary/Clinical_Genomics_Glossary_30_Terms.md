# Week 5 — Clinical Genomics Glossary

## Purpose

This glossary summarises 30 important terms covered during Week 5 clinical genomics and variant interpretation training.

| # | Term | Definition |
|---|---|---|
| 1 | Genomic Medicine | The use of genomic information to support diagnosis, treatment, risk assessment and healthcare decisions. |
| 2 | NHS Genomic Medicine Service | The NHS service that provides genomic testing and genomic medicine within the UK healthcare system. |
| 3 | National Genomic Test Directory | The NHS directory that defines which genomic tests are commissioned and for which clinical indications and patient groups. |
| 4 | Clinical Indication | The clinical reason or condition that provides the basis for requesting a genomic test. |
| 5 | Genomic Laboratory Hub | An NHS genomic laboratory service responsible for delivering and supporting genomic testing within the NHS Genomic Medicine Service. |
| 6 | Variant | A difference in a DNA sequence compared with a reference sequence. |
| 7 | Pathogenic | A variant classification indicating that available evidence supports a disease-causing effect. |
| 8 | Likely Pathogenic | A variant classification indicating that the available evidence supports a probable disease-causing effect, but is not sufficient for the highest level of certainty. |
| 9 | Variant of Uncertain Significance (VUS) | A variant for which the available evidence is currently insufficient to classify it as benign or disease-causing. |
| 10 | Likely Benign | A variant classification indicating that the available evidence supports a probable benign effect. |
| 11 | Benign | A variant classification indicating that available evidence supports a non-disease-causing effect. |
| 12 | ClinVar | A public database that collects and provides access to submitted interpretations of the clinical significance of genetic variants. |
| 13 | gnomAD | The Genome Aggregation Database, which provides population variation and allele-frequency information from large-scale sequencing datasets. |
| 14 | ClinGen | The Clinical Genome Resource, which develops expert-curated resources for understanding the clinical relevance of genes and genetic variants. |
| 15 | ACGS | The Association for Clinical Genomic Science, which publishes UK best-practice guidance for clinical genomic variant interpretation and classification. |
| 16 | HGVS | Human Genome Variation Society nomenclature used to describe genetic variants in a standardised way. |
| 17 | Transcript | An RNA sequence produced from a gene that can be used as a reference for describing transcript and coding-sequence variants. |
| 18 | MANE Select | A transcript selected through the MANE collaboration as a representative transcript with matching RefSeq and Ensembl annotations. |
| 19 | Molecular Consequence | The predicted effect of a genetic variant on a transcript or protein, such as missense, synonymous, frameshift or stop-gained. |
| 20 | Missense Variant | A variant that changes one amino acid in the resulting protein sequence. |
| 21 | Stop-Gained Variant | A variant that introduces a premature termination codon, potentially producing a shortened protein. |
| 22 | Frameshift Variant | An insertion or deletion that changes the reading frame of a coding sequence. |
| 23 | Synonymous Variant | A coding variant that does not change the encoded amino acid. |
| 24 | Intron Variant | A variant located within an intronic region of a gene. |
| 25 | Loss-of-Function (LoF) | A genetic change that reduces or eliminates the normal function of a gene product. |
| 26 | Nonsense-Mediated Decay (NMD) | A cellular mechanism that can recognise and degrade mRNA containing certain premature termination codons. |
| 27 | Allele Frequency | The proportion of chromosomes in a population carrying a particular allele. |
| 28 | Variant Classification | The process of assigning a clinical significance category to a genetic variant using available evidence and an established classification framework. |
| 29 | Evidence-Based Variant Interpretation | The process of interpreting a variant using documented evidence from appropriate clinical, population, functional, computational and other relevant sources rather than relying on prediction or assumption alone. |
| 30 | ACMG/AMP Framework | A widely used framework that combines different categories of evidence to support classification of sequence variants into clinical significance categories. |

## Key Learning

Clinical variant interpretation requires multiple sources of evidence. Molecular consequence, population frequency, clinical databases, gene-disease relationships and other evidence should be considered together using an established classification framework.

> This glossary is for bioinformatics and clinical genomics training and does not represent patient-specific clinical interpretation.
