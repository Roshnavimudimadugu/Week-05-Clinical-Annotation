# Clinical Genomics Glossary

## Purpose

This folder contains a glossary of important terminology used in clinical genomics and genetic variant interpretation.

## Main File

### Clinical_Genomics_Glossary_30_Terms.md

This file contains 30 important clinical genomics terms and their definitions.

The glossary covers concepts including:

- Genomic medicine
- NHS Genomic Medicine Service
- National Genomic Test Directory
- Clinical indications
- Variant classification
- ClinVar
- gnomAD
- ClinGen
- ACGS
- HGVS
- Transcripts
- MANE Select
- Molecular consequences
- Missense variants
- Stop-gained variants
- Frameshift variants
- Synonymous variants
- Intron variants
- Loss-of-function
- Nonsense-mediated decay
- Allele frequency
- ACMG/AMP framework

## Learning Outcome

This glossary provides a concise reference for terminology used throughout the Week 5 clinical genomics and variant interpretation work.

> This material represents bioinformatics training and educational work and is not intended for patient-specific clinical interpretation.
