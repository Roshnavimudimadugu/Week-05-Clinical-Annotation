# SnpEff Evidence

## Purpose

This folder contains supporting evidence from the SnpEff annotation performed during Week 5.

## Contents

### SnpEff_Annotation_Evidence.md

This file summarises the molecular consequences and SnpEff impact categories for the 10 selected variants used in the Week 5 clinical variant annotation.

### Original SnpEff VCF

The complete SnpEff-annotated VCF was generated during the Galaxy workflow and is retained locally because its file size is too large for normal GitHub upload.

## Role of SnpEff

SnpEff was used to annotate variants with information including:

- Gene
- Transcript
- HGVS notation
- Molecular consequence
- SnpEff impact
- Loss-of-function annotations where available

## Important Note

SnpEff impact categories describe predicted molecular consequences and should not be treated as clinical classifications.

The clinical interpretation of variants requires additional evidence from resources such as ClinVar, gnomAD, ClinGen and established variant-classification guidelines.

> This folder contains bioinformatics training evidence and does not represent patient-specific clinical interpretation.
