# ACGS Evidence

## Purpose

This folder contains the ACGS guidance used during Week 5 to understand clinical genomic variant classification.

## Main Resource

### ACGS 2024 UK Practice Guidelines for Variant Classification

The guideline was used to understand:

- Evidence-based variant classification
- ACMG/AMP evidence categories
- Evidence strength
- PVS1 loss-of-function evidence
- Considerations related to transcript and variant location
- Integration of different types of evidence

## Relevance to This Project

The ACGS guidance provided the framework for understanding how molecular and clinical evidence should be considered during variant interpretation.

The guidance was particularly relevant when considering loss-of-function evidence for the MCPH1 stop-gained variant.

## Learning Outcome

This resource supports understanding of how established clinical variant-classification guidance is applied during evidence-based variant interpretation.

> The guideline is retained as a training and reference resource and does not represent a patient-specific clinical interpretation.
