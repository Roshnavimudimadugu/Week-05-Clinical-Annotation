# Supporting Evidence

## Purpose

This folder contains supporting resources and evidence collected during the Week 5 clinical variant annotation and interpretation process.

The evidence is organised according to the database, guideline or resource from which the information was obtained.

## Subfolders

### ACGS

Contains the ACGS 2024 guideline used to understand evidence-based clinical variant classification.

### ClinVar

Contains supporting records and screenshots from ClinVar searches performed for selected variants.

### SnpEff

Contains documentation of the SnpEff annotation used to identify molecular consequences and impact categories for the selected variants.

The complete SnpEff-annotated VCF is retained locally because its file size is too large for normal GitHub upload.

### gnomAD

Contains supporting evidence from gnomAD, including variant searches and regional coverage information.

### ClinGen_MCPH1

Contains supporting information related to the MCPH1 gene-disease relationship and loss-of-function interpretation, including ClinGen and PVS1-related resources.

## Purpose of the Evidence

These resources provide an audit trail showing the databases, guidelines and supporting information consulted during the Week 5 variant annotation and interpretation process.

> These materials are retained for bioinformatics training and documentation purposes and do not represent patient-specific clinical interpretation.
