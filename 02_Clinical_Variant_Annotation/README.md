# Clinical Variant Annotation

## Purpose

This folder contains the structured annotation of 10 selected genetic variants from the SnpEff-annotated VCF used during Week 5.

## Main File

### 10_Variant_Annotation.md

This file contains a structured annotation table for 10 selected variants.

The table records:

- Gene
- HGVS variant notation
- Transcript
- Molecular consequence
- ClinVar classification
- Review status
- gnomAD frequency
- Disease association
- Evidence notes
- Conflicting evidence
- Interpretation limitation

## Annotation Resources

The variant annotations were considered using information from relevant molecular, clinical and population resources, including:

- SnpEff
- ClinVar
- gnomAD
- ClinGen

## Interpretation Note

The information in this folder documents variant annotation and evidence collected during bioinformatics training.

Molecular consequences and database annotations should not be interpreted as patient-specific clinical diagnoses.

> This work is intended for bioinformatics and educational purposes.
