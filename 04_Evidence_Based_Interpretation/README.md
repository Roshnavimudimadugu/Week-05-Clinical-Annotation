# Evidence-Based Variant Interpretation

## Purpose

This folder contains an explanation of the principles of evidence-based clinical variant interpretation.

## Main File

### Why_Variant_Interpretation_Is_Evidence_Based_and_Not_Guesswork.md

This document explains why variant interpretation requires integration of multiple sources of evidence rather than relying on a single database, computational prediction or molecular consequence.

The document covers:

- SnpEff molecular consequences
- ClinVar clinical classifications
- gnomAD population frequency
- ClinGen gene-disease validity
- ACGS guidance
- Evidence strength
- Conflicting evidence
- Loss-of-function evidence
- Why rarity alone does not establish pathogenicity

## Example Variant

The MCPH1 variant:

`NM_024596.5:c.2253C>G (p.Tyr751*)`

is used as an example of how molecular annotation can be considered together with gene-disease and other evidence.

## Learning Outcome

This section demonstrates an understanding that clinical variant interpretation is a structured, evidence-based process in which different types of evidence are evaluated according to established guidelines.

> This material represents bioinformatics training and educational work and is not intended for patient-specific clinical interpretation.
