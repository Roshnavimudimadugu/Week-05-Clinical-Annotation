# NHS Genomics Context

## Purpose

This folder contains the learning material and notes related to genomic medicine within the NHS.

## Contents

### NHS_Genomics_Context.md

This file summarises the key concepts covered during the NHS Genomics Education Programme training, including:

- NHS Genomic Medicine Service
- National Genomic Test Directory
- Clinical indications
- Patient eligibility
- Genomic Laboratory Hubs
- Evidence-led genomic test selection

### NHS Genomics Education Programme Certificates

This folder also contains evidence of completion of the relevant NHS Genomics Education Programme modules:

- Genomics 101: Genomics in Healthcare
- Genomics 101: Investigating the Genome Part 2 — The Tests

## Learning Outcome

This section demonstrates an understanding of the clinical and organisational context of genomic testing within the NHS.

> This material represents bioinformatics training and educational work and is not intended for patient-specific clinical interpretation.
